VERIROTA - ERP & POWER BI WEB SİTESİ

ÇALIŞTIRMA
1. ZIP dosyasını bilgisayarınıza çıkarın.
2. VS Code ile erp-bi-web klasörünü açın.
3. index.html dosyasını açın.
4. Live Server eklentisini kurup sağ alttaki "Go Live" seçeneğine tıklayın.
   Eklenti olmadan da index.html dosyasına çift tıklayarak tarayıcıda açabilirsiniz.

DOMAIN / YAYINLAMA
Bu klasör statik HTML/CSS/JS sitesidir. Netlify, Vercel veya bir hosting firmasına yüklenebilir.
Domain satın aldıktan sonra hosting panelinden domain DNS kayıtlarını yayın sağlayıcınıza yönlendirin. Yayına almadan önce iletişim bilgilerini ve fiyatları mutlaka kontrol edin.
